📦 Amazon Frontend Clone

An Amazon-inspired frontend web application built with HTML, CSS, and JavaScript.
This project replicates the look and feel of Amazon’s e-commerce platform, focusing on UI design, responsiveness, and interactive components.

🚀 Features

🏠 Homepage Layout – Amazon-style navigation bar, search bar, and hero section.

🛒 Product Listings – Grid-based product display with images, prices, and ratings.

🔍 Search Functionality – Search input with category filtering.

📦 Cart System (Frontend) – Add/remove items from the cart dynamically.

📱 Responsive Design – Mobile-friendly layout with adaptive navigation.

🌙 Dark/Light Mode (optional enhancement).

🛠️ Tech Stack

HTML5 – Semantic structure.

CSS3 – Flexbox & Grid for layout, animations for smooth UI.

JavaScript (Vanilla/ES6) – DOM manipulation, dynamic cart, search filter.
